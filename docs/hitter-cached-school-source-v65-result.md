# Draft background recovered without new college collection

2026-10-03. The existing cached draft files recover broad school background for
18,280 source rows, including 8,179 of the 30,506 historical evaluation rows.
They do not recover a player's precise class year or prove a better forecast.
The retained hitter candidate, research explorer and protected 2026 are unchanged.
The active goal remains open pending a matched predictive comparison.

## What was missing and what is now available

Earlier source work already identified uneven school-class coverage and tested a
draft-age substitute without earning an upgrade. That is not a new discovery.
The additional repair here uses school names that were already in the captured
draft files but were not used by the retained hitter source. It does not fetch
more college information or repeat the compact-readiness/age experiments.

Exact school names can be matched to classified draft records available by each
forecast origin. An institution match establishes broad college, HS or JC
background—not whether another player was a junior or senior. Explicit HS/CC
names also supply background. Conflicting names and unmatched aliases stay
unknown. No later institution evidence fills an earlier forecast and no outcomes
enter this classification. The original school-class unknown flag stays intact.

## Scope and limitations

The separate overlay retains all 63,282 input identities and every original
column. Among the evaluation rows, 12,340 now have a broad background; 18,166
remain unknown. These are repeated player-origin rows, not unique newly
classified players. College indicators differ in 5,039 evaluation rows; that
count is not a gain in predictive accuracy.

For the 2011–2017 first-year drafted cohorts, 284–328 backgrounds per origin are
recovered. That supplies older training examples in a more comparable form to
modern school-known entrants. The 2019 source gap also matters. It does not
increase the number of players who actually made an immediate MLB jump, nor
erase the canceled 2020 minor season.

There are 33 source rows with conflicting institution classifications. Exact
matching intentionally misses aliases such as LSU. Four implementation tests
check dates, abstention, whitespace normalization and the distinction between
background and precise class. One duplicate raw pick has identical school
evidence and is deduplicated; conflicting school records would stop the run.
Unresolved drafted rows are persisted separately. Historical captures remain
reconstructed evidence with ordinary source limitations, not flawless ground truth.

Keep the retained model as baseline. Write one source-only matched fitting
contract, use the same retained learners/settings, and inspect actual training
support before fitting. Compare next-year appearance/workload and resulting
offense with hitting held fixed first. Preserve all current players, minors and

This repair earns a predictive test, not adoption.
