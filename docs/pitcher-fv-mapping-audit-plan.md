# Pitcher controlled-WAR-to-FV mapping audit plan

Status: deterministic audit; no alternate grade scale will be fitted.

Determine whether the low count of high-FV pre-MLB pitchers is created by the
pitcher FV mapping or already exists in expected controlled WAR. Report the exact WAR
boundary for each displayed grade, current counts, maximum expected WAR, and the
spread of underlying affiliated-translated WAR rates.

The mapping must remain monotonic. No target grade count, individual outside FV,
manual floor, hitter-scale substitution, or post-result threshold adjustment is
allowed. This audit can identify the layer responsible; it cannot promote a change.
