# Repair observed MLB absence without inventing health

2026-10-03, before reconstruction. This source milestone follows the completed
V59 forecast and source reviews. It fits no predictive model. The purpose is to
make the existing dated availability evidence usable for the next coherent
workload comparison, not spend another batch optimizing sparse injury features.

Use the frozen V59 normalized transaction versions, V53 source identities and
verified V46 preceding/late MLB windows through 2024. No 2026 observations.
Historical publication-vintage limitations remain. Independently select the
latest eligible version by transaction/person and order by occurrence date,
with availability date bounded by December 31. Do not import the untracked
legacy modeling runners into the new source adapter.

Distinguish reported injury placement, observed MLB roster return, clinical
recovery, uncertain duration and missing observation scope. A safe reported
MLB recall/activation ends the continuing roster-absence observation, not the
injury itself. Named paternity, bereavement, restricted/admin/suspended and
all-star activations must not clear a separate medical spell. Medical-list
activation and ordinary roster return are recorded as different closures.

A positive PA window can end a captured continuing-absence interval only when
its start is strictly after the latest placement/transfer in that interval.
If an entry falls inside/after the PA window, keep it unresolved: all window
PA might predate that entry. Later new placements reopen a separate interval.
Observed PA supplies an upper bound on roster absence, not an exact return day
or proof the player is healthy in December. Do not assume an unobserved return
occurred at the beginning of the window, nor assume absence continued until then.

Produce spell records, known-return bounds and a distinct source-quality flag.
For ambiguous closures, report a conservative possible-absence upper bound,
never reinterpret it as measured missed days or erase previous injury history.
Missing captured medical scope stays unknown; no PA is not proof of ongoing IL.
Keep origin and training identities unchanged. Old forecasts remain exact.
