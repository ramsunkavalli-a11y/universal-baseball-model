# Current prospect talent comparison

Last updated: 2026-09-12  
Status: **FIRST LOGICAL PEAK-TALENT BOARD COMPLETE**

This is a talent-rate board, not a playing-time or contract-value list. It ranks
non-MLB players age 23 or younger using only translated StatsAPI performance, age,
level and evidence. The public list is joined only after every score is complete.

## Boundaries

Do not force the model toward public ranks. A disagreement is acceptable when the
StatsAPI case is explicit. Raw pitch quality below AAA, hitter defense/position and
physical tools remain missing. Older prospects are reported as outside the validated
pre-24 peak model rather than silently treated as failures.
