# Past-only count baseline: complete, not adopted

2026-10-05. One fixed historical replacement was fitted and reviewed. Its source
meaning is coherent, and it predicts the eight next-year MLB event counts jointly.
It does not beat the incumbent full-model hitting/value forecasts. Keep the
incumbent, the existing team-filtered explorer and the completed one-time 2026
evaluation unchanged. This result is historical development evidence through
target 2025, not another held-out 2026 test.

Read the [contract](hitter-count-baseline-contract.md),
[pre-fit source review](hitter-count-baseline-source-review.md) and
[thirteen post-fit player walks](hitter-count-baseline-player-review.md).
The [previous horizon qualification](hitter-shared-production-horizon-qualification.md)
preserves the earlier scores but narrows what its foreign subgroup result means.

## What changed in the test

The old shared-production test pooled already forecasted foreign probabilities
with observed domestic equivalencies. This test instead reconstructs foreign
past probabilities and past references from dated source counts, never reading
the old foreign future probability or persistence coefficients. Domestic inputs
remain same-season selected-mover level equivalencies. Foreign inputs are local
relative production, **not already established MLB-equivalent talent**.

One common 1,200-PA prior and normalized 1/.8/.6 recency produce a past baseline.
Eight symmetric softmax coordinates predict the arithmetic event distribution
using count log likelihood, rather than treating squared log-coordinate forecasts
as arithmetic expectations. Raw pooled event rates and four competing MLB-only
quality summaries are removed. Demographic, exposure, role, draft, branch scouting
and branch tracking evidence remain. This is a joint design replacement, not a
causal attribution to a single field or likelihood.

All 105 heads converged in the declared settings and independently replay.
Original PA are exactly fixed, all 30,506 original forecasts remain and thirteen
source additions have their separate fixed research PA reference. There are no
new playing-time fits, algorithm searches, cohort-selected hybrids or 2026 reads.

This is not a 2021-only defeat. No origin/stage hitting score deteriorates over
the predeclared 5% warning threshold, but that is a safety warning threshold,
**not** a license to adopt a broadly losing replacement.

## Real gains and unresolved problems

For upper-minor never-debut players, hitting RMSE improves 2.56325 to 2.54320
and value RMSE 0.301695 to 0.298740. However, expected value falls 177.49 to
154.96 versus actual 196.73: individual accuracy and cohort totals disagree.
For lower-minor never-debut players, hitting RMSE improves 3.17908 to 3.03835
and expected value falls 16.18 to 10.18 versus actual 9.48. Only 54 lower-stage
rows have next-year MLB hitting labels; this is not a certified DSL lifetime
projection. Established current-MLB hitting worsens 1.70546 to 1.71982, and value
RMSE 1.06776 to 1.07762. Removing incumbent quality inputs did not establish a
better general batting baseline.

All active originals' equal-origin PA-weighted HR frequency is 3.206% predicted
versus 3.188% actual. Across the same 4,538 supported active originals, event
log loss improves 1.477634 to 1.476064 and Brier 0.701021 to 0.700615 relative to
the old direct future profile. Upper-minor HR moves from 2.159% in that old profile
to 2.835%, near actual 2.807%. This is genuine event-distribution progress, not a
full-model value win. The old direct value arm kept incumbent established-MLB
rates; its profile and delivered-value comparisons have different routing.

The 253-row foreign-history original group has 28 active rows. Its hitting RMSE
barely improves 1.88024 to 1.87218, but value worsens 0.49309 to 0.49829 and MAE
0.13483 to 0.14667. Predicted HR 4.051% exceeds actual 3.218%, walks 9.071% exceed
7.990% and K 21.019% undershoot 22.948%. Its total 35.42 is near actual 33.41, but
these opposing individual/event errors mean the foreign transfer is not calibrated.
This power failure and sparse first-arrival support block an unqualified win.

Thirteen additions improve delivered RMSE relative to the old failed shared
production branch (1.56902 to 1.43564) but worsen conditional hitting RMSE
(2.98205 to 3.20812). Expected value 4.91 remains below actual 8.34 at 743.39
research PA versus actual 1,625. There is no fabricated incumbent for additions.
Other failed foreign/job branches with different addition PA are secondary, not
a fixed-opportunity attribution.

No-arrival expected value falls 225.93 to 207.18, but its RMSE worsens 0.06939 to
0.07198. Large false highs can worsen while many tiny positives shrink. This is
why neither aggregate totals nor many correctly predicted zero-work players can
stand in for individual delivered-value accuracy.

## Public comparison is qualified, not a superiority claim

The same 2,627 matched current-MLB rows have 2,088 active hitting labels.
Origin-centered common-rate RMSE is incumbent 1.72848, count 1.71858,
Steamer 1.77459 and ZiPS 1.75336. But future-league-relative hitting on these same
rows is incumbent 1.66475 versus count 1.67421: the ranking reverses with the
environment convention. Both calculations are retained. The shift between
origin and future league means is common to each year's actual target, and
squared-error rankings can change with that shift; this is not a demonstrated
public-system talent win. Release timing, park context and target environment
remain incompletely harmonized. ZiPS workload is not certified here.

## Player findings and disposition

The full walks show more than a headline:

- Judge's rookie rate worsens +0.264 to -0.171; his established 2023-origin rate
  improves +3.899 to +4.455 but remains below actual +7.558.
- Yordan improves only +0.455 to +0.481 against actual +5.648; his translated
  minor profile still lowers the output, not because 57 old DSL PA dominate.
- Suzuki's reconstructed Japanese record is used strongly, but the forecast
  is +3.505 against actual +1.175. Underestimated PA partly hides that optimism
  in delivered value. Only two never-debut active NPB people inform that fold's
  broader NPB learner, with zero exact active profile peers.
- Yoshida worsens +0.327 to +1.061 against actual -0.444; removing old NPB
  evidence lowers the new forecast 0.777 despite its diluted 12.7% mass share.
- Khris Davis is the biggest harm: restoring power increases his forecast when
  his actual next-year production falls. Misner's near-exact delivered value
  instead masks hitting and workload errors. Both remain in the report.

Do not deploy this fixed replacement, but do not erase its useful source and
event-likelihood work. It repairs the temporal-meaning gap and the old common
power underprediction; it does not validate the inherited prior, selected-mover
translation, overseas adaptation or loss function for player-value selection.
Before any further fitted variant, use these unchanged outputs to locate errors
by origin-known production/exposure/level profiles. Separate translation/precision
failures from optimizing event probabilities rather than delivered hitting value.
Do not tune a favorable-subgroup hybrid, named-player boost or new alpha from
this result. The practical hitter goal remains active, not falsely completed.
