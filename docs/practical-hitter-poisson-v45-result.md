## Decision and remaining work

Reject this fixed loss/link replacement, not every count-model possibility.
Do not retune to these names, invent Poisson event probabilities, or attach
its variance to a different point model. Source/game-count repairs and the
reversible retirement rule remain useful independently of this failed test.

The practical model is not finished: the main remaining public gap is expected
playing time, with consequential debut/return and late-job errors. Another
generic learner is not the obvious next move. Inventory actual historical
within-season role/promotion evidence and prior tests before deciding whether
a bounded role-trajectory addition can be supported. No new fit is authorized
by this report until that source/design checkpoint is completed. Keep the
foreign-universe, roster-vintage and sparse elite-profile qualifications visible.
