# Annually linked career-state replay plan

**Status:** locked before implementation and scoring  
**Production effect:** none

## Purpose

Replace the eventual-tier-first shortcut with a year-by-year career path while keeping
real workload, inactivity, return, role and performance dependence intact.

## Chronology

The durable 2025 progression package is for current forward research only. A historical
forecast must refit every advancement equation and destination share using outcomes
completed before that forecast origin. It may not use the 2025 coefficients in a 2021
replay. Donor careers are eligible only when their entire six-year window ended before
the forecast origin. Partial 2026 evidence is prohibited.

## Path construction

1. Sample arrival timing from the cutoff-valid arrival model; non-arrival stays zero.
2. Draw a complete eligible historical path block, never isolated annual seasons.
3. Classify the first active season with the frozen 200/400 workload thresholds.
4. For later years, use only the draw's prior-year workload and forecast-age evidence
   in the cutoff-refitted advancement equation.
5. When simulated state and the donor block diverge, resample the remaining tail from
   donors sharing player type, current state and path year. Retain the longest possible
   tail block; use a declared pooled fallback when support is insufficient.
6. Keep workload, role and performance from the same donor tail. Do not apply a second
   workload multiplier or convert state into a skill bonus.
7. Accrue service, cost and value only after the production path is complete.

Report every tail resample, fallback, missing-age fallback and feature-range
extrapolation. State must be monotone and may move at most once per player-year.

## Comparison and decision

On identical players compare the current capped tier-linked path, the arrival-only
whole-path baseline and the annually linked state/tail-block challenger.

Score arrival and state probabilities with log loss/Brier; zero-inclusive WAR with
CRPS, paired squared error and aggregate bias; then inspect supported age, level,
player-type and arrival-probability groups. MAE is descriptive only. The disclosed
2021-to-2025 replay is development evidence, not promotion evidence. Current rankings
remain unchanged until a separately frozen future confirmation passes.
