# Use complete position history for arm scope

Before any skill scoring, an independent check found 100 historical arm records
whose native split ledger showed only outfield exposure but whose official
fielding history included another position. Native splits can omit tiny position
appearances. A whole-player opportunity denominator cannot be certified as
outfield-only using those splits alone. This qualifies the earlier pilot and
extension scope flags; their raw arithmetic and receiving reconciliation stand.

Prepare a separate corrected annual view using the already audited official MLB
fielding history. Sum official outs across all positions, including pitching;
DH carries no fielding outs. Mark isolated outfield quality valid only with
positive official OF outs, no official other-position outs and reconciled arm
credit. Keep mixed-position records and every source discrepancy available, not
recast as bad outfield talent or zero contribution. Official innings establish
position scope only; they never replace real arm opportunities.

Rebuild the same predeclared three-calendar-year support audit from this corrected
view. Earlier scope-derived labels and support counts are superseded, not erased.
The reusable audit runner is unchanged, runs in a separate output directory and
uses the same thresholds, chronology, source walkthrough and peer-selection
rules. No scores, learned fits or protected 2026 outcomes have been examined.
