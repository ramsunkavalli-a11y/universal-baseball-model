# Diagnose the completed count model errors

2026-10-05. The previous goal turn made progress: it completed and pushed one
105-head historical comparison, qualified a temporal-meaning defect and reviewed
thirteen player cases. This checkpoint uses those unchanged saved outputs to
identify the highest-value repair. It fits nothing, changes no forecast and
accesses no 2026 outcomes. The historical outcomes are already exposed; these
are descriptive diagnostics, not a fresh independent test or calibrated subgroup
selection. Do not adopt a favorable subgroup or a setting from these tables.

Keep all 30,506 original forecasts and thirteen separately reported source
additions. Use only forecast-origin information to define diagnostic groups:
talent route; current dominant domestic or foreign league by actual PA; age;
recent MLB exposure; total supported evidence; MLB-versus-other evidence shares;
raw recent MLB homer/strikeout profile; and origin-known scouting coverage.
Use fixed, interpretable boundaries, not outcome-selected cutpoints. Report
group counts, active hitting labels, distinct people, actual/expected PA/value,
rate errors, event calibration, and origin-wise changes. Retain sparse groups
and explicitly warn about tiny active samples. No-arrivals stay in delivered
scores but never acquire an invented zero hitting-talent label.

For actual MLB participants decompose delivered error exactly into:

1. Hitting error at fixed expected PA: expected PA times the forecast-minus-actual
   batting rate, divided by 600.
2. Playing-time error at observed hitting: expected-minus-actual PA times the
   actual batting rate per PA plus the unchanged replacement contribution.

Their sum equals the delivered-value error. The count-minus-incumbent squared
error change equals the change in the first term squared plus its interaction
with the second term. Playing time itself is identical in both arms. Keep
non-arrivals' squared-error change separate because their actual hitting is
unobserved. This is an explanatory counterfactual using known outcomes, never
a prospective forecast or recommendation to feed future stats into a model.

For the count model only, split its rate error into the actual eight-event value
terms using origin and future environment references. Do not invent incumbent
event probabilities from its scalar batting estimate. Aggregate homer agreement
does not prove player-level power calibration. Show the variation of HR/K/walk
errors within origin-defined groups, and the contribution to batting error from
walks, singles, extra-base hits and HR.

Audit overseas adaptation in actual mature active training rows for the three
fixed overseas cases. Compare the fixed L2 curvature with data curvature for the
NPB/KBO share coefficients and record their actual likelihood gradients. This
can show how strongly a declared penalty competes with sparse information; it
cannot establish that setting that penalty to zero would improve prediction.
Never run an unannounced alternative fit or select a new penalty from this check.

Retain existing fixed cases and choose at most eight focal walks to explain the
largest mechanisms. Include gains, harms, false highs/lows, an ordinary case and
minor/foreign evidence. Add cases if necessary rather than dropping a category.
Trace real counts, translated baseline, prior share, fitted event corrections,
fixed PA/value, outcomes and origin-selected production peers. Use already
completed walks where they match; new cases require actual reconstructed source
and saved-model mechanics. No next fitted experiment before readable review.

Exit: reproducible diagnosis and at most two supported priority mechanisms for
one subsequent matched contract. Distinguish translation/precision, sparse
overseas adaptation, objective weighting and hitting/workload interactions.
Do not label unit tests or explanatory identities an accuracy gain. Keep the
incumbent, public anchors, frozen packages and the completed 2026 evaluation.
