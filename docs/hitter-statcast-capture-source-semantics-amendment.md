# Preserve unusual source pitch codes during historical contact capture

2026-10-04. The first capture adapter accepted four monthly chunks, then stopped
when another response contained a pitch-result code other than X. It had incorrectly
equated a source contact filter with a guarantee that every raw pitch code is X.
The monthly query and requested years do not change. The stopped adapter and its
receipts are preserved; use a new version to resume the identical request set.

Save the full filtered response before classification. Retain and report every
non-X row, its event and description, instead of silently deleting it or rerunning
with another filter. Official hit and full-contact counts, true-PA identity and
dated result reconciliation remain the acceptance tests. The measured BBE adapter
still requires terminal type X and excludes bunts; this amendment does not allow
a foul measurement to become a hitting feature.

This is a source-semantic correction before any new fitting or score, not a
relaxed predictive acceptance rule. Complete source discrepancies and player
walkthroughs before approving earlier history for model use. Successful prior
chunks are reused after verifying their original contract, original collector
hash and output hashes. The prior capture's stopped process is terminal, not an
unobserved background job.
