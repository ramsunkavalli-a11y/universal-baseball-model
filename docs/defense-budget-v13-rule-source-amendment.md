# Starting roles differ from later position appearances

2026-10-07. All 87 pitching starts were captured. The initial certification
recognizes 63 Ohtani games but stops on two: 2022-08-21, game 662805, and
2023-07-27, game 717243. Both have Ohtani in the original batting order and as
the starting pitcher; the final boxscore lists only P. Requiring a later DH
appearance to prove a starting DH role is the wrong measurement.

[Rule 5.11(b) in the 2022 official rules](https://img.mlbstatic.com/mlb-images/image/upload/mlb/hhvryxqioipb87os1puw.pdf)
establishes both roles when the starting pitcher bats for himself. Use this
generic rule when the boxscore certifies the pitching start, original batting
slot and pitcher code, even if no later DH appearance is listed. Preserve an
explicit rule-derived evidence basis. A pinch hitter, relief pitcher, absent
starting slot, missing pitcher role or pre-2022 game still does not qualify.

This changes the source certification requirement, not a fitted parameter or
outcome-selected forecast. The original module and first-amended runner are
archived, and the prior contract remains intact with this additive correction.
No accuracy score or new model fit has been produced.
