# Prospect broad-history positive-tail chronology correction

**Status:** frozen before corrected scoring

The first dry run exposed a protocol error before its result was accepted or committed:
the planned 2008–2012 fit uses two-year outcomes through 2014, which are not known at
the 2013 evaluation snapshot. Those scores are invalid and must not be cited.

The mechanical correction is to fit on 2008–2010 origins only. Their two-year outcomes
end in 2012, before every 2013–2017 and 2021–2023 evaluation snapshot. Nothing else may
change: the player universe, `0.25` component-WAR threshold, `C=0.1`, basic feature set,
inverse-player-frequency weights, evaluation years, scores, uncertainty, subgroup
rules and pass bar remain exactly as frozen in the original plan.

This correction is required by chronology; it is not a model choice made from the dry
run's scores.
